🍄 Binary Prediction of Poisonous Mushrooms
This repository contains a mushroom classification dataset, designed to help researchers, data scientists, and mycologists predict whether a 
mushroom is poisonous or edible based on its physical characteristics. Using machine learning and statistical analysis, we can build a model to
classify mushrooms into two categories:

✅ Edible (Safe to Consume)
❌ Poisonous (Toxic or Harmful)

The dataset is ideal for binary classification tasks, anomaly detection, and feature engineering related to fungal taxonomy and toxicology.

📌 Dataset Features
🍄 Mushroom Characteristics
Cap Properties: Shape, surface texture, color.
Gill Features: Attachment type, spacing, color.
Stalk Attributes: Height, width, surface texture, color.
Ring Type & Number: Presence of rings around the stalk.
Spore Print Color: Used for species identification.
Habitat & Growth Conditions: Grass, forests, paths, or decaying wood.

⚠️ Target Variable (Binary Classification)
Poisonous (1) → The mushroom is toxic and unsafe to eat.
Edible (0) → The mushroom is safe for consumption.

🔍 Key Insights & Use Cases
🚨 Poisonous vs. Edible Mushroom Identification

Predicting toxicity based on physical attributes.
Detecting patterns in poisonous mushrooms (e.g., cap color, gill attachment).
Identifying high-risk species commonly confused with edible ones.
